**Live:** https://raushan1107.github.io/Intelligent-Enterprise-Development-with-.NET-8-Azure-AI/

## What's inside

- `index.html` — portal home
- `LearnEFCore.html`, `OOPs-EF-Core-File Handling-lab.html` — labs
- `capstone1-3.html` — capstone projects
- `demo*.html` — demos

## How to use

Static site: open `index.html` in a browser, or use the GitHub Pages link above.
